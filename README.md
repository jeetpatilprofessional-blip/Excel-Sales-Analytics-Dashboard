# Sales Analytics Dashboard | Microsoft Excel

## Project Overview
This project focuses on analysing sales performance and transforming raw sales data into an interactive dashboard using Microsoft Excel.

The dashboard provides insights into revenue, profit, customer performance, product categories, regional sales and monthly sales trends.

## Dataset
- 1,000 sales records
- Order ID and Order Date
- Customer ID and Customer Name
- Product ID and Product Name
- Item Category and Region
- Quantity Sold
- Unit Price and Cost Amount
- Sales Amount and Profit

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Analysis
- Interactive Dashboard

## Dashboard Features
- Total Revenue
- Total Quantity Sold
- Total Orders
- Average Order Value
- Total Customers
- Monthly Sales Trend
- Sales by Region
- Profit by Region
- Top 5 Customers by Sales
- Sales vs Cost by Product
- Sales by Item Category
- Quantity Sold by Product
- Orders Over Time

## Interactive Features
The dashboard includes slicers for:
- Month
- Region
- Item Category

These filters allow users to explore sales performance across different dimensions.

## Business Objectives
- Analyse monthly sales performance.
- Identify profitable regions and products.
- Understand customer purchasing patterns.
- Compare sales and cost performance.
- Identify important sales trends.

## Key Learning Outcomes
- Practical experience with Excel data analysis.
- Creating Pivot Tables and Pivot Charts.
- Building interactive dashboards.
- Using formulas for business calculations.
- Presenting data through visual reports.
